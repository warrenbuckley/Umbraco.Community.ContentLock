## Features

<CardGrid stagger>
	<Card title="Content Locking" icon="seti:lock">
		Lock content nodes while editing to prevent conflicts. Locked nodes become read-only for all other editors, with publish/save/unpublish actions hidden.
	</Card>
	<Card title="Real-Time Updates" icon="random">
		Lock state is broadcast instantly to all connected backoffice users via SignalR — no page refresh required.
	</Card>
	<Card title="Online Users" icon="group">
		See who else is active in the backoffice via the header app. Get notified with sounds when editors join or leave.
	</Card>
	<Card title="Audio Calling" icon="phone">
		Peer-to-peer WebRTC audio calls between backoffice editors — no external service needed for most networks.
	</Card>
	<Card title="Dashboard" icon="list-format">
		View all locked content in one place. Bulk unlock multiple nodes at once from the Content Lock dashboard.
	</Card>
	<Card title="Permissions" icon="approve-check">
		Fine-grained `ContentLock.Unlocker` permission lets designated users unlock content locked by others.
	</Card>
</CardGrid>
